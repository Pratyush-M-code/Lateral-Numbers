What is this project about?

This project is to help build an intuitive understanding of Complex numbers and fuctions.

How should I use this?

Currently this project is a work in progress

4 Operations are accepted =>
- Addition(+): To add 2 complex numbers together
- Subtraction(-): To subtract 2 complex numbers.
- Multiplication(*): To scale the cartestian plane to multiply 2 complex numbers together. - Division(/): To scale the cartestian plane with respect to a vector to divide 2 complex numbers together.

Keep in Mind

- All complex numbers are to be declared in the following format => (a + bi)
- There may be some bugs, if you find any, please contact me here.

Examples to try out

- (3 + 2i) + (4 + 1i)
- (3 + 2i) - (4 - 1i)
- (2 + 4i) / (3 - 7i)
- (5 - 3i) + (2 + 6i)
- (1 + 2i) * (1 - 2i)
